# Java Learning & Projects

A general repository for my Java practice, exercises, and projects. Programs are organized by package, from small console exercises to larger applications.

## What's Inside

- **Practice programs**: small exercises focused on one concept at a time
- **Projects**: larger programs that combine several concepts
- **Assignments**: coursework and lab exercises

## Topics Covered

- Variables, data types, and operators
- User input and output
- Conditionals and loops
- Methods and classes
- Arrays and collections
- Object-oriented programming
- Data structures and algorithms

## Project Structure

```
JAVA_Program/
├── PackageName/
│   └── ClassName.java
├── AnotherPackage/
│   └── AnotherClass.java
└── README.md
```

Each folder is a Java package that holds related programs.

## Getting Started

### Requirements

- Java JDK 17 or newer
- VS Code with the Extension Pack for Java, or any Java IDE

### Run in VS Code

1. Clone the repo:
   ```bash
   git clone <your-repo-url>
   ```
2. Open the folder in VS Code.
3. Open any program and click **Run** above the `main` method.

### Run from the command line

```bash
javac PackageName/ClassName.java
java PackageName.ClassName
```

## Notes

- Every program has a `main` method and can be run on its own.
- Code is written for learning, so it favors clarity over optimization.
